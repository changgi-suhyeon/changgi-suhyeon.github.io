# RSVP API 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 모바일 청첩장의 참석 여부(RSVP)를 받아 저장하고, 관리자만 조회할 수 있는 API를 Cloudflare Workers + D1으로 구현한다.

**Architecture:** 의존성 없는 단일 fetch 핸들러가 세 개의 라우트(`OPTIONS`/`POST`/`GET /rsvp`)를 처리한다. 검증·인증·레이트리밋·해시는 전부 순수 모듈로 분리해 plain vitest로 테스트하고, D1이 실제로 오가는 경로는 배포된 Worker를 향한 스모크 스크립트로 검증한다. 브라우저에서 오는 값은 아무것도 신뢰하지 않는다.

**Tech Stack:** TypeScript (strict) · Cloudflare Workers · D1 · Turnstile · wrangler · vitest

**저장소:** `marriage-invitation-worker` (private) — 로컬 `~/Desktop/Project/marriage-invitation-worker`

**설계 문서:** 사이트 저장소의 `docs/superpowers/specs/2026-08-08-mobile-wedding-invitation-design.md` §6

## Global Constraints

- TypeScript `strict: true`. `any` 금지.
- **런타임 의존성 0.** 라우트가 3개뿐이라 프레임워크를 넣을 이유가 없다. devDependencies만 사용한다.
- 허용 Origin은 `https://changgi-suhyeon.github.io` 하나뿐. CORS 와일드카드 금지.
- 시크릿 3종 `ADMIN_TOKEN` / `TURNSTILE_SECRET` / `IP_SALT` 는 **절대 커밋하지 않는다.** 원격은 `wrangler secret put`, 로컬은 `.dev.vars`(gitignore됨).
- 검증 규칙: 이름 1~20자 · 메시지 0~500자 · 참석 시 인원 1~10 · 식사 인원 0 이상 참석 인원 이하 · `side`는 `'groom' | 'bride'`.
- 레이트리밋: 동일 IP 해시가 **최근 10분(600,000ms) 내 5건을 초과**하면 429.
- 원문 IP를 저장하지 않는다. `SHA-256(ip + IP_SALT)` 의 hex만 남긴다.
- 계약 타입(`src/contract.ts`)은 사이트 저장소 `src/lib/rsvp-contract.ts`가 원본이다. 변경 시 양쪽을 함께 고친다.
- 에러 응답 본문은 항상 `{ error: string, fields?: ValidationError[] }` 형태다.

- [ ] **Step 4: src/validate.ts 구현**

```ts
import type { RsvpSubmission, Side, ValidationError } from './contract'

export const NAME_MAX = 20
export const MESSAGE_MAX = 500
export const PARTY_MAX = 10

const SIDES: readonly string[] = ['groom', 'bride']
const PHONE_RE = /^[0-9+\-\s]{8,20}$/

export type ValidationResult =
  | { ok: true; value: RsvpSubmission }
  | { ok: false; errors: ValidationError[] }

export function validateSubmission(input: unknown): ValidationResult {
  if (typeof input !== 'object' || input === null || Array.isArray(input)) {
    return { ok: false, errors: [{ field: '_', message: '요청 본문이 올바르지 않습니다.' }] }
  }

  const raw = input as Record<string, unknown>
  const errors: ValidationError[] = []

  const side = raw.side
  if (typeof side !== 'string' || !SIDES.includes(side)) {
    errors.push({ field: 'side', message: '신랑측 또는 신부측을 선택해 주세요.' })
  }

  const name = typeof raw.name === 'string' ? raw.name.trim() : ''
  if (name.length === 0) {
    errors.push({ field: 'name', message: '성함을 입력해 주세요.' })
  } else if (name.length > NAME_MAX) {
    errors.push({ field: 'name', message: `성함은 ${NAME_MAX}자 이내로 입력해 주세요.` })
  }

  const attending = raw.attending
  if (typeof attending !== 'boolean') {
    errors.push({ field: 'attending', message: '참석 여부를 선택해 주세요.' })
  }

  // 불참이면 인원 정보를 받지 않고 0으로 정규화한다.
  let partySize = 0
  let mealCount = 0
  if (attending === true) {
    partySize = toInt(raw.partySize)
    mealCount = toInt(raw.mealCount)

    if (!Number.isInteger(partySize) || partySize < 1 || partySize > PARTY_MAX) {
      errors.push({
        field: 'partySize',
        message: `참석 인원은 1명 이상 ${PARTY_MAX}명 이하로 입력해 주세요.`,
      })
    }
    if (!Number.isInteger(mealCount) || mealCount < 0 || mealCount > partySize) {
      errors.push({ field: 'mealCount', message: '식사 인원은 참석 인원을 넘을 수 없습니다.' })
    }
  }

  const phone = typeof raw.phone === 'string' ? raw.phone.trim() : ''
  if (phone.length > 0 && !PHONE_RE.test(phone)) {
    errors.push({ field: 'phone', message: '연락처 형식을 확인해 주세요.' })
  }

  const message = typeof raw.message === 'string' ? raw.message.trim() : ''
  if (message.length > MESSAGE_MAX) {
    errors.push({ field: 'message', message: `메시지는 ${MESSAGE_MAX}자 이내로 입력해 주세요.` })
  }

  const turnstileToken = typeof raw.turnstileToken === 'string' ? raw.turnstileToken : ''
  if (turnstileToken.length === 0) {
    errors.push({
      field: 'turnstileToken',
      message: '보안 확인이 완료되지 않았습니다. 잠시 후 다시 시도해 주세요.',
    })
  }

  if (errors.length > 0) return { ok: false, errors }

  return {
    ok: true,
    value: {
      side: side as Side,
      name,
      attending: attending as boolean,
      partySize,
      mealCount,
      ...(phone.length > 0 ? { phone } : {}),
      ...(message.length > 0 ? { message } : {}),
      turnstileToken,
    },
  }
}

function toInt(value: unknown): number {
  if (typeof value === 'number') return value
  if (typeof value === 'string' && value.trim() !== '') return Number(value)
  return NaN
}
```

- [ ] **Step 3: src/crypto.ts 구현**

Workers 런타임에 `crypto.subtle.timingSafeEqual`이 있지만 표준이 아니라서 쓰지 않는다. 대신 양쪽을 SHA-256으로 해시해 **항상 같은 길이(32바이트)**로 만든 뒤 상수 시간 비교한다. 이러면 길이 차이로 정보가 새지 않는다.

```ts
const encoder = new TextEncoder()

async function sha256(input: string): Promise<Uint8Array> {
  const digest = await crypto.subtle.digest('SHA-256', encoder.encode(input))
  return new Uint8Array(digest)
}

/**
 * 타이밍 세이프 문자열 비교.
 * 두 값을 해시해 길이를 고정한 뒤 전 바이트를 XOR 누적한다.
 * 조기 반환이 없으므로 일치 지점에 따라 소요 시간이 달라지지 않는다.
 */
export async function safeEqual(a: string, b: string): Promise<boolean> {
  const [ha, hb] = await Promise.all([sha256(a), sha256(b)])
  let diff = 0
  for (let i = 0; i < ha.length; i++) {
    diff |= (ha[i] as number) ^ (hb[i] as number)
  }
  return diff === 0
}

/** 원문 IP는 저장하지 않는다. salt를 섞어 역산을 막는다. */
export async function hashIp(ip: string, salt: string): Promise<string> {
  const bytes = await sha256(`${ip}:${salt}`)
  return Array.from(bytes)
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('')
}
```

```ts
import type { RsvpRecord, RsvpSummary } from './contract'

/**
 * records는 created_ms 내림차순이어야 한다.
 * 같은 (측, 이름) 조합은 가장 앞에 오는 것(=최신)만 집계에 반영한다.
 * 중복 제출을 막지 않는 대신 여기서 정리한다.
 */
export function summarize(records: RsvpRecord[]): RsvpSummary {
  const seen = new Set<string>()
  const summary: RsvpSummary = {
    total: 0,
    attending: 0,
    notAttending: 0,
    groomGuests: 0,
    brideGuests: 0,
    totalMeals: 0,
  }

  for (const r of records) {
    const key = `${r.side}|${r.name}`
    if (seen.has(key)) continue
    seen.add(key)

    summary.total += 1
    if (!r.attending) {
      summary.notAttending += 1
      continue
    }

    summary.attending += 1
    summary.totalMeals += r.mealCount
    if (r.side === 'groom') summary.groomGuests += r.partySize
    else summary.brideGuests += r.partySize
  }

  return summary
}
```

```ts
export const TURNSTILE_VERIFY_URL =
  'https://challenges.cloudflare.com/turnstile/v0/siteverify'

interface TurnstileResponse {
  success?: boolean
}

/**
 * Turnstile 토큰을 Cloudflare에 확인한다.
 * 어떤 이유로든 확신할 수 없으면 false를 돌려준다 — 실패 시 통과시키지 않는다.
 */
export async function verifyTurnstile(
  token: string,
  secret: string,
  remoteIp: string | null,
  fetchImpl: typeof fetch = fetch,
): Promise<boolean> {
  if (token.length === 0) return false

  const form = new FormData()
  form.append('secret', secret)
  form.append('response', token)
  if (remoteIp) form.append('remoteip', remoteIp)

  try {
    const res = await fetchImpl(TURNSTILE_VERIFY_URL, { method: 'POST', body: form })
    if (!res.ok) return false
    const data = (await res.json()) as TurnstileResponse
    return data.success === true
  } catch {
    return false
  }
}
```

```ts
import type { RsvpSubmission } from './contract'
import { corsHeaders, isAllowedOrigin } from './cors'
import { hashIp } from './crypto'
import { json } from './http'
import { exceedsRateLimit, windowStart } from './ratelimit'
import { verifyTurnstile } from './turnstile'
import { validateSubmission } from './validate'

export interface Env {
  DB: D1Database
  ALLOWED_ORIGIN: string
  ADMIN_TOKEN: string
  TURNSTILE_SECRET: string
  IP_SALT: string
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const origin = env.ALLOWED_ORIGIN
    const url = new URL(request.url)

    if (request.method === 'OPTIONS') {
      return new Response(null, { status: 204, headers: corsHeaders(origin) })
    }

    if (url.pathname !== '/rsvp') {
      return json({ error: 'not found' }, 404, origin)
    }

    if (request.method === 'POST') return handlePost(request, env, origin)
    if (request.method === 'GET') return json({ error: 'not implemented' }, 501, origin)

    return json({ error: 'method not allowed' }, 405, origin)
  },
}

async function handlePost(request: Request, env: Env, origin: string): Promise<Response> {
  // 관문 1 — Origin. 위조 가능하므로 CSRF 수준 방어일 뿐이다.
  if (!isAllowedOrigin(request.headers.get('Origin'), env.ALLOWED_ORIGIN)) {
    return json({ error: 'forbidden origin' }, 403, origin)
  }

  let body: unknown
  try {
    body = await request.json()
  } catch {
    return json({ error: '요청 본문을 읽을 수 없습니다.' }, 400, origin)
  }

  // 관문 2 — 필드 검증. 클라이언트 검증은 신뢰하지 않는다.
  const result = validateSubmission(body)
  if (!result.ok) {
    return json({ error: '입력값을 확인해 주세요.', fields: result.errors }, 400, origin)
  }
  const submission: RsvpSubmission = result.value

  const ip = request.headers.get('CF-Connecting-IP')

  // 관문 3 — Turnstile. 봇 방어의 주력.
  const humanOk = await verifyTurnstile(
    submission.turnstileToken,
    env.TURNSTILE_SECRET,
    ip,
  )
  if (!humanOk) {
    return json({ error: '보안 확인에 실패했습니다. 새로고침 후 다시 시도해 주세요.' }, 403, origin)
  }

  // 관문 4 — 레이트리밋.
  const nowMs = Date.now()
  const ipHash = ip ? await hashIp(ip, env.IP_SALT) : null

  if (ipHash) {
    const row = await env.DB.prepare(
      'SELECT COUNT(*) AS c FROM rsvp WHERE ip_hash = ? AND created_ms >= ?',
    )
      .bind(ipHash, windowStart(nowMs))
      .first<{ c: number }>()

    if (exceedsRateLimit(row?.c ?? 0)) {
      return json({ error: '잠시 후 다시 시도해 주세요.' }, 429, origin)
    }
  }

  const inserted = await env.DB.prepare(
    `INSERT INTO rsvp (created_ms, side, name, attending, party_size, meal_count, phone, message, ip_hash)
     VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
     RETURNING id`,
  )
    .bind(
      nowMs,
      submission.side,
      submission.name,
      submission.attending ? 1 : 0,
      submission.partySize,
      submission.mealCount,
      submission.phone ?? null,
      submission.message ?? null,
      ipHash,
    )
    .first<{ id: number }>()

  return json({ ok: true, id: inserted?.id ?? null }, 200, origin)
}
```

```ts
async function handleGet(request: Request, env: Env, origin: string): Promise<Response> {
  const header = request.headers.get('Authorization') ?? ''
  const token = header.startsWith('Bearer ') ? header.slice(7) : ''

  // 토큰이 비어 있어도 비교를 건너뛰지 않는다 — 응답 시간 차이를 만들지 않기 위해서다.
  if (!(await safeEqual(token, env.ADMIN_TOKEN))) {
    return json({ error: 'unauthorized' }, 401, origin)
  }

  const { results } = await env.DB.prepare(
    'SELECT * FROM rsvp ORDER BY created_ms DESC',
  ).all<RsvpRow>()

  const records = (results ?? []).map(toRecord)
  return json({ records, summary: summarize(records) }, 200, origin)
}
```

순수 로직은 vitest가 덮지만 **D1과 Turnstile이 실제로 오가는 경로는 배포된 것에만 존재한다.** 이 스크립트가 그 경로를 검증한다.

```bash
#!/usr/bin/env bash
# 사용법: BASE=https://... TOKEN=<ADMIN_TOKEN> ./scripts/smoke.sh
set -euo pipefail

BASE="${BASE:?BASE 환경변수가 필요합니다}"
TOKEN="${TOKEN:?TOKEN 환경변수가 필요합니다}"
ORIGIN="https://changgi-suhyeon.github.io"

pass=0
fail=0

check() { # check <설명> <기대코드> <실제코드>
  if [ "$2" = "$3" ]; then
    echo "  ok   $1 ($3)"
    pass=$((pass + 1))
  else
    echo "  FAIL $1 — 기대 $2, 실제 $3"
    fail=$((fail + 1))
  fi
}

code() { # code <curl 인자들...>
  curl -s -o /dev/null -w '%{http_code}' "$@"
}

echo "== POST /rsvp =="

check "Origin 없으면 403" 403 \
  "$(code -X POST "$BASE/rsvp" -H 'Content-Type: application/json' -d '{}')"

check "잘못된 Origin이면 403" 403 \
  "$(code -X POST "$BASE/rsvp" -H 'Origin: https://evil.example' \
      -H 'Content-Type: application/json' -d '{}')"

check "필드가 비면 400" 400 \
  "$(code -X POST "$BASE/rsvp" -H "Origin: $ORIGIN" \
      -H 'Content-Type: application/json' -d '{}')"

check "turnstile 토큰이 가짜면 403" 403 \
  "$(code -X POST "$BASE/rsvp" -H "Origin: $ORIGIN" -H 'Content-Type: application/json' \
      -d '{"side":"groom","name":"스모크","attending":true,"partySize":1,"mealCount":1,"turnstileToken":"fake"}')"

echo "== GET /rsvp =="

check "토큰 없으면 401" 401 "$(code "$BASE/rsvp")"
check "토큰이 틀리면 401" 401 "$(code "$BASE/rsvp" -H 'Authorization: Bearer wrong-token')"
check "올바른 토큰이면 200" 200 "$(code "$BASE/rsvp" -H "Authorization: Bearer $TOKEN")"

echo "== 라우팅 =="

check "알 수 없는 경로는 404" 404 "$(code "$BASE/nope")"
check "OPTIONS는 204" 204 "$(code -X OPTIONS "$BASE/rsvp" -H "Origin: $ORIGIN")"

echo
echo "통과 $pass · 실패 $fail"
[ "$fail" -eq 0 ]
```
